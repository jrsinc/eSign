# Method 365 validation package

Word documents for validating Method 365 (version 2.0.0) under 21 CFR Part 11 and 21 CFR Part 211, in the JRS document layout. Start with **JRS-VP2026-001-IDX Validation Package Index**, which lists every document in life-cycle order and what is still needed before release.

- Document numbers use the placeholder `JRS-VP2026-001`; replace it with the JRS validation project number.
- These are drafts and templates: approvals, executed results and signatures are completed on controlled copies, not here.
- When Word asks to update fields on opening, answer Yes so the table of contents gets its page numbers.

| Life-cycle step | Documents |
|---|---|
| 0 | IDX Package Index and gap map |
| 1–2 | VP Validation Plan · RA Risk Assessment · JRS-FRM-IT-001 Data Integrity Risk Assessment Checklist |
| 3 | URS User Requirements Specification (Part 11 clause map) |
| 4 | SD System Description · FS Functional Specification · DS Design Specification · SCB Security and Configuration Baseline · SDLC Evidence and Test Report · KIL Known Issues List |
| 5 | IQ Installation Qualification · OQ Operational Qualification |
| 6 | PQ Performance Qualification (UAT) |
| 7 | RTM Traceability Matrix · DL Deviation Log · VSR Validation Summary Report |
| 8 | L11 21 CFR 11.100(c) certification letter |
| 9 | CR Change Request form · SOP list · PRR Periodic Review Report |
